# writui has moved

writui now lives in [aakashns/aak.sh](https://github.com/aakashns/aak.sh/tree/main/writui),
and its site is [writui.aak.sh](https://writui.aak.sh).

- **Install:** `curl -fsSL https://writui.aak.sh/install.sh | bash`
- **Already installed?** Run `writui upgrade`. Versions up to 0.20.0 upgrade
  to 0.21.0 from this repo, and from then on upgrades come from aak.sh.
- Releases up to 0.21.0 stay here; newer ones are tagged `writui-v*` on
  [aak.sh](https://github.com/aakashns/aak.sh/releases?q=writui-v&expanded=true).

This repo is archived and kept for its releases and history.
